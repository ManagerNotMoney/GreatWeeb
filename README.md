# 🌿 GreatWeeb — каннабис-дополнение для Minecraft

**GreatWeeb** — плагин для Paper, добавляющий выращивание, переработку и употребление каннабиса, табака и производных продуктов.  
В плагине есть два штамма каннабиса (сатива и индика), гашиш, спайс, табак, сигареты, медицинские продукты, бонги, сушилки, удобрения, брикеты, паки, брендирование и развитая система передозировки.

> ⚠️ Плагин предназначен для взрослых серверов с соответствующими правилами. Используйте на свой страх и риск.

---

## 🚀 Возможности

- **Выращивание**: посадка семян сативы, индики и табака; полив, удобрение, увлажнение льдом, ультрафиолет, сбор ножницами или секатором.
- **Переработка**: сушка соцветий, бошек, измельчённой травы и табака; измельчение ножницами; крафт брикетов и паков.
- **Изготовление**: косяки, бонги, удобрения, гашиш, гашишное масло, гашишный пирог, спайс, канна-брауни, печенье, медицинская жвачка, сигареты, пачки и блоки сигарет.
- **Употребление**: курение косяков, бонгов и сигарет; поедание продуктов с отложенными эффектами.
- **Система передозировки**: отслеживание частоты и смешивания веществ; негативные эффекты при превышении порога.
- **Визуальные эффекты**: зелёный/серый дым, частицы при курении, сообщения о запахе nearby-игрокам.
- **Бонг**: зарядка разными веществами, курение с зажигалкой, разрядка.
- **Сушка**: блок-сушка с GUI и прогрессом; сохраняется в `config.yml`.
- **Брендирование брикетов**: нанесение названия бренда переименованной бумагой.
- **Команды для администраторов**: выдача предметов, управление эффектами, очистка истории курения.
- **Книга-гайд**: `/gw guide`.

## 📦 Установка

1. Скачайте `.jar` плагина.
2. Поместите файл в папку `plugins/` сервера.
3. Перезапустите сервер.

**Системные требования:**
- Сервер: Paper, ориентировочно **1.21.5+** — код использует материалы `RESIN_BRICK`, `BREEZE_ROD`, `BUSH`, `TALL_DRY_GRASS`, `LEAF_LITTER`.
- Java: **25** для Paper 26.x

## 🔧 Команды

Большинство команд требуют права `greatweeb.admin`. Исключение — `/gw guide`: она доступна игроку без права.

| Команда | Описание |
|---------|----------|
| `/gw guide` | Выдать книгу-гайд. Только игроку, право не требуется |
| `/gw all` | Выдать большинство предметов плагина |
| `/gw smell [ник]` | Убрать зелёный дым (запах) у игрока |
| `/gw nosmoke [ник]` | Очистить историю курения и сбросить данные передозировки |
| `/gw sativa <seed|bud|boshka|joint|briquette|pack>` | Предметы сативы |
| `/gw indica <seed|bud|boshka|joint|briquette|pack>` | Предметы индики |
| `/gw gash <gash|oil|cake|briquette|pack>` | Гашиш и производные |
| `/gw spice <spice|briquette|pack>` | Спайс и производные |
| `/gw medical <boshka|joint|gum>` | Медицинские предметы |
| `/gw tobacco <seed|tobacco|filter|cigarette>` | Табак и сигареты |

Одиночные предметы через `/gw <предмет>`:

`bong`, `fertilizer`, `spice`, `shredded`, `brownie`, `cookie`, `gash`, `gash_oil`, `gash_briquette`, `gash_pack`, `spice_briquette`, `spice_pack`, `medical_boshka`, `medical_joint`, `medical_gum`, `tobacco_seed`, `tobacco`, `box_fertilizer`, `cigarette_pack`, `cigarette_block`, `filter`, `cigarette`, `watering_can`, `dried_tobacco`, `shredded_tobacco`.

> Примечание: `dried_tobacco` и `shredded_tobacco` поддерживаются командой, но не попали в подсказку/`tab-complete`. `/gw all` не выдаёт секатор, сушилку, `dried_tobacco` и `shredded_tobacco`.

## 🌱 Выращивание

1. **Посадка**: используйте семена сативы, индики или табака на вспаханной грядке. Блок становится пшеницей, привязанной к сорту.
2. **Полив**: если куст засох, используйте ведро воды. Лейку можно наполнить из воды; ПКМ по кусту (не в приседе) поливает до 3×3 кастомных растений вокруг и опустошает лейку.
3. **Удобрение**:
   - Обычное удобрение можно применить только на только что посаженный куст (возраст 0). Оно даёт бонус к урожаю, но **не ускоряет рост**.
   - Боксовое удобрение также применяется только на возраст 0, даёт бонус к урожаю и **защищает от засыхания**.
   - Костная мука ускоряет рост сативы/индики. Для табака костная мука не обрабатывается.
4. **Увлажнение льдом**: лёд работает для сативы/индики и даёт одну защиту от следующего засыхания. Для табака лёд не обрабатывается.
5. **Ультрафиолет**:
   - Перламутровая квампа над растением: +20% к шансу роста.
   - Фиолетовое стекло над перламутровой квампой: +30%.
   - Зелёное стекло над малахитовой квампой: ультрахлорофилит, рост медленнее, но при сборе сативы/индики даёт +2–3 соцветия.
6. **Сбор**: используйте ножницы или секатор на созревшем растении. Секатор даёт больше урожая и опыта. После сбора сатива/индика начинают расти заново; табак также сбрасывается на возраст 0.
7. **Разрушение куста**: выпадает семя, а у созревшего растения — соответствующий продукт. При вытаптывании грядки выпадает семя.

## 🔥 Сушка

**Сушка** — кастомный блок (бочка). Поставьте и откройте ПКМ.

Слоты:
- **1** — вход.
- **2** — индикатор прогресса.
- **3** — основной выход.
- **4** — дополнительный выход.

Процессы:
- Соцветие → Бошка (сорт сохраняется).
- Бошка → Медицинская бошка + Гашишное масло.
- Измельчённая марихуана ×3 → Медицинская бошка + Гашишное масло.
- Табак → Высушенный табак.

Одна операция занимает примерно **45 секунд** (900 тиков, прогресс прибавляется каждые 5 секунд). Если выходной слот занят неподходящим предметом или заполнен, результат падает рядом с сушилкой.

Сушилки сохраняются в `config.yml` в секции `drying-racks` и загружаются при запуске.

## ✂️ Измельчение

Возьмите в основную руку сырьё, в дополнительную — обычные **ножницы**, и кликните ПКМ.

- Соцветие сативы/индики → **3** измельчённой марихуаны.
- Бошка сативы/индики → **2** измельчённой марихуаны.
- Высушенный табак → **4** измельчённого табака.

Ножницы теряют 5 прочности. Секатор для измельчения не используется.

## 🧱 Брикеты, паки и брендирование

- **Брикет сативы/индики** — 8 бошек + 1 бумага (бесформенный).
- **Брикет гашиша** — 8 гашиша + 1 бумага.
- **Брикет спайса** — 8 спайса + 1 бумага.
- **Пак** — 9 брикетов в сетке 3×3. Паки сативы, индики, гашиша и спайса можно ставить как блок: при разрушении выпадает 9 брикетов. Также есть крафт-распаковка.
- **Брикет**: обычный ПКМ разламывает один брикет в 8 единиц. Shift+ПКМ разламывает весь стак, если не выполняется брендирование.
- **Брендирование**: Shift+ПКМ брикетом с переименованной бумагой в дополнительной руке. Название добавляется в лор, бумага расходуется.

## 💨 Употребление

Курение имеет кулдаун **10 секунд**. Еда также обновляет этот кулдаун (но съесть её можно, даже если он активен). Медицинская жвачка кулдаун не ставит.

### Косяк
- Основная рука: косяк сативы/индики/медицинский.
- Дополнительная рука: огниво.
- ПКМ — закурить. Эффекты через **20 секунд**, медицинский — через **10 секунд**.

Эффекты:
- **Сатива**: Скорость II (30 с), Регенерация I (7 с), Голод II (60 с) + зелёный дым.
- **Индика**: Замедление I (20 с), Ночное зрение (20 с), Голод I (40 с) + дым.
- **Медицинский**: Регенерация I (10 с), Замедление I (20 с), Голод I (5 с).

Сатива/индика считаются в систему передозировки. Медицинский — нет.

### Бонг
- **Зарядка**: Shift+ПКМ пустым бонгом, наполнитель — в дополнительной руке. Подходят бошка сативы/индики, гашиш, спайс, медицинская бошка.
- **Курение**: заряженный бонг в основной руке + огниво в дополнительной → ПКМ. Эффекты через **10 секунд**.
- **Разрядка**: ПКМ заряженным бонгом без приседа — вернуть содержимое.

Эффекты:
- **Сатива**: Скорость II (30 с), Регенерация I (7 с), Голод II (60 с) + дым.
- **Индика**: Замедление I (20 с), Ночное зрение (20 с), Голод I (120 с).
- **Гашиш**: Замедление III (30 с), Регенерация II (20 с), Слепота (8 с), Голод III (100 с).
- **Спайс**: Скорость II (50 с), Голод III (120 с), Прыгучесть I (50 с) + дым.
- **Медицинская**: Регенерация I (10 с), Замедление I (20 с), Голод I (5 с).

Сатива/индика/гашиш/спайс считаются в передозировку. Медицинская — нет.

### Сигарета
- Основная рука: сигарета.
- Дополнительная рука: огниво.
- ПКМ — закурить. Эффекты через **13 секунд**: Усталость I (20 с), серый дым. С шансом 50% — Иссушение I (10 с) и сообщение о кашле nearby-игрокам.

### Еда
- **Канна-брауни**: Регенерация II (40 с), Замедление I (30 с), Голод III (80 с), Тошнота (10 с). Считается в передозировку с порогом 4.
- **Вкусное печенье**: Регенерация I (15 с), Тошнота (10 с). В передозировку не считается.
- **Гашишный пирог**: Регенерация I (40 с), Замедление I (60 с). Считается как гашиш.

### Медицинская жвачка
ПКМ — съесть и убрать зелёный дым. Кулдаун не ставится.

## ☠️ Передозировка

Система отслеживает приём веществ за последние **90 секунд** и факт смешивания.

Пороги:
- Сатива, индика, гашиш, гашишный пирог — **6**.
- Спайс — **3**.
- Канна-брауни — **4**.

Смешивание разных веществ/сортов в пределах окна вызывает передозировку сразу.

Симптомы:
- Тошнота III (30 с)
- Слепота (15 с)
- Слабость II (60 с)
- Отравление II (10 с)
- Замедление III (20 с)
- Для спайса дополнительно Иссушение II (120 с)

После первой передозировки история сбрасывается. При повторном превышении порога эффекты применяются снова, но игрок получает сообщение «Мне становится ещё хуже...».

## 🧪 Медицинские продукты

- **Медицинская бошка** получается только в сушилке из обычной бошки или измельчённой марихуаны ×3. Прямого крафта медицинской бошки нет.
- **Медицинский косяк** — крафт из бумаги и медицинской бошки.
- **Медицинская жвачка** — крафт из медицинской бошки, слизи и сахара; убирает запах.

| **Гашишный брикет** | 8 гашиша + 1 бумага |
| **Пак гашиша** | 9 гашишных брикетов (3×3) + распаковка |
| **Спайс** | Светопыль + 2 измельчённой марихуаны + гашишное масло |
| **Брикет спайса** | 8 спайса + 1 бумага |
| **Пак спайса** | 9 брикетов спайса (3×3) + распаковка |
| **Бонг** | Стеклянная бутылка + палка + огниво **или** стеклянная бутылка + стержень ифрита |
| **Сушка** | 6 дубовых досок + 2 нити (shaped: `WWW`, `S S`, `WWW`) |
| **Удобрение** | Костная мука + гнилая плоть + измельчённая марихуана |
| **Боксовое удобрение** | 4 костной муки + измельчённая марихуана + 3 табака + любой лёд |
| **Канна-брауни** | 2 пшеницы + какао-бобы + сахар + гашишное масло |
| **Вкусное печенье** | 2 пшеницы + какао-бобы + медицинская бошка → 2 шт. |
| **Гашишный пирог** | 2 гашишного масла + гашиш + 3 пшеницы |
| **Медицинский косяк** | 2 бумаги + медицинская бошка (вертикально) |
| **Медицинская жвачка** | Медицинская бошка + слизь + сахар |
| **Секатор** | Ножницы + 2 железных слитка (shaped: ` N `, `I I`) |
| **Лейка** | Ведро + 2 железных слитка + нить (бесформенный) |
| **Фильтр** | Белая шерсть + 2 бумаги (бесформенный) |
| **Сигарета** | Фильтр + 2 бумаги + измельчённый табак (бесформенный) |
| **Пачка сигарет** | 20 сигарет + бумага (ПКМ) + крафт-распаковка |
| **Блок сигарет** | 9 пачек (бесформенный) + распаковка |
| **Копчение бошки** | Соцветие в коптильне → бошка (250 тиков, 0.5 опыта) |

> Все рецепты регистрируются автоматически при загрузке плагина.

## 🛠️ Для разработчиков

Архитектура:
- `GreatWeeb` — главный класс, регистрация событий и менеджеров.
- `StrainItemsImpl` — общая логика предметов сативы и индики.
- `RecipeManager` — крафты и печные/коптильные рецепты.
- `OverdoseListener` — отслеживание передозировки.
- `DelayedEffectManager`, `SmokeEffectManager` — отложенные эффекты и дым.
- `DryingRackManager` — циклическая обработка сушилок и сохранение в `config.yml`.
- `*Listener` — обработка взаимодействий игроков.

Баланс задан в коде. `config.yml` используется для сохранения сушилок, поэтому утверждение «плагин не использует конфигурационные файлы» неверно.
